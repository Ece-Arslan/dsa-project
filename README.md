# dsa-project
# DSA 210 Project – Consumer Spending Behavior Analysis

## Project Topic
This project analyzes consumer spending behavior during Black Friday using demographic and product-related variables.

## Dataset
- Black Friday Dataset (Kaggle)
- Supplementary E-commerce Pricing Dataset (Kaggle)

## Methods Used
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Hypothesis Testing
- Random Forest Regression
- Linear Regression Comparison

## Main Findings
- Product categories are strong predictors of purchase behavior.
- Random Forest performed significantly better than Linear Regression.
- Pricing and discount-related patterns may influence consumer spending behavior.
